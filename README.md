## 🧭 How I approach development

I value **KISS, pragmatic design, maintainable project structures, and a good developer experience**. I prefer solutions that are understandable and practical over unnecessary complexity.

I use **AI-assisted development tools and coding agents extensively**, both for implementation and for exploring unfamiliar technologies.

My focus is on understanding the systems I'm building, verifying their behavior through meaningful tests, and reviewing changes according to their risks. Security-sensitive logic, database changes, networking, and infrastructure configuration deserve more attention than routine implementation details.

Not everything works on the first attempt. I've spent plenty of time troubleshooting API performance, refactoring deployment scripts, and testing configurations until they behaved as intended. Those problems have been some of my most valuable learning experiences.

I'm still building technical depth, particularly around backend development, Linux infrastructure, security, and reliability.
